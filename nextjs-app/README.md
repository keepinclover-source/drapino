# راهنمای اتصال و استفاده از Next.js App Router و دیتابیس

این پوشه شامل ساختار استانداردهای بکند **Next.js (App Router)** برای سامانه دراپینو است:

### مسیرهای API:
- `GET/POST /api/cities`: دریافت و ثبت شهرهای عملیاتی و فیلد `otherCoveredCities` (سایر شهرهای تحت پوشش).
- `GET/POST /api/orders`: دریافت و ثبت سفارشات با فیلتر دقیق شهر در تابلوی شکار (`?city=تهران`).
- `GET/POST /api/vendors`: ثبت‌نام همکاران با انتخاب شهر و مشخص کردن محدوده اقماری تحت پوشش.
- `GET/POST /api/coupons`: مدیریت کدهای تخفیف با اعمال سقف عددی.

### اتصال به دیتابیس (Prisma / PostgreSQL / MySQL):
برای استقرار در پلتفرم‌هایی مثل Vercel یا سرور مستقل، می‌توانید متغیر `DATABASE_URL` را در فایل `.env` تعریف کرده و از ابزار Prisma یا Drizzle جهت اتصال به MySQL یا PostgreSQL استفاده نمایید.
